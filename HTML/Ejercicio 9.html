Etiquetas HTML de formato


Etiqueta de énfasis

< gm >: Permite enfatizar un texto.

Etiqueta de marcado

< mark >: Permite marcar un texto.

Etiquetas de encabezado

<hl>: Permite incluir encabezados en el documento.

Etiqueta para indicar importancia en el texto

<strong >:Permitemarcar un texto como importante.
